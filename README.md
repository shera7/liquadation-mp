# Актив.Каталог — MVP (Фаза 1)

Цифровая витрина ликвидационного имущества: каталог, карточка товара, заявки с
уведомлением в Telegram, простая админка, импорт из Excel/CSV.

Стек: Next.js 14 (App Router) + TypeScript + Tailwind CSS + PostgreSQL + Prisma.

## Что уже реализовано (Фаза 1)

- Главная, каталог с поиском/фильтрами/сортировкой/пагинацией, карточка товара
- Форма заявки по товару + быстрая заявка без товара
- Telegram-уведомление менеджеру при новой заявке
- Админка: список товаров, создание товара, смена статуса, удаление
- CRM: список заявок, смена статуса заявки
- Импорт Excel/CSV с отчётом об ошибках (upsert по ID)
- Адаптивная вёрстка (mobile-first)
- Базовый SEO: `sitemap.xml`, `robots.txt`, метатеги карточки товара

## Что НЕ реализовано в этом скелете (сознательно, для скорости первого запуска)

- **Авторизация и роли в админке.** Раздел `/admin` сейчас ничем не защищён.
  Перед реальным использованием — либо поставить Basic Auth на уровне
  reverse-proxy/хостинга, либо подключить NextAuth с ролями
  Администратор/Менеджер/Контент-менеджер (раздел 24 ТЗ).
- **Реальная загрузка фото/документов.** Модели `ProductImage`/`ProductDocument`
  в схеме есть, но UI загрузки файлов и интеграция с Cloudinary/S3 — следующий шаг.
- Массовое редактирование/экспорт в Excel, визуальный маппинг колонок при импорте,
  сравнение товаров, избранное, мультивалютные курсы, мультиязычность (RU/UZ),
  подробная аналитика (GA/Метрика), журнал действий администратора, CAPTCHA.
  Это всё — Фаза 2/3, они не потеряны, а осознанно вынесены за скобки первого запуска.

## Запуск локально

```bash
# 1. Установить зависимости
npm install

# 2. Поднять PostgreSQL (проще всего — Docker)
docker run --name asset-db -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=asset_liquidation -p 5432:5432 -d postgres:16

# 3. Скопировать .env
cp .env.example .env
# и заполнить DATABASE_URL, TELEGRAM_BOT_TOKEN, TELEGRAM_MANAGER_CHAT_ID

# 4. Применить схему БД
npm run db:push

# 5. Наполнить демо-данными (опционально)
npm run db:seed

# 6. Запустить
npm run dev
```

Сайт: http://localhost:3000
Админка: http://localhost:3000/admin

## Настройка Telegram-уведомлений

1. В Telegram написать **@BotFather**, команда `/newbot`, получить токен.
2. Вставить токен в `.env` как `TELEGRAM_BOT_TOKEN`.
3. Менеджеру написать что угодно созданному боту.
4. Открыть в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`,
   найти `"chat":{"id": ...}` — это `TELEGRAM_MANAGER_CHAT_ID`.

## Формат Excel/CSV для импорта

Колонки (см. `/admin/import`): `ID, Название, Категория, Подкатегория,
Производитель, Модель, Год, Состояние, Количество, Цена, Валюта,
Местонахождение, Описание, Статус`.

Значения `Статус`: `В продаже / Забронировано / Продано / Снято с продажи`.
Значения `Состояние`: `Новое / Б/У / Требует ремонта`.

## Рекомендуемый порядок дальнейшей работы (в Claude Code)

1. Запустить проект локально, прогнать `npm run db:seed`, проверить сценарии
   из раздела 32 ТЗ (заявка по товару, общая заявка, Telegram-уведомление).
2. Подключить загрузку фото (Cloudinary — самый быстрый вариант для старта).
3. Закрыть `/admin` авторизацией.
4. Добавить массовое редактирование и экспорт в Excel (раздел 28–29 ТЗ).
5. Деплой: Vercel (frontend) + управляемый Postgres (Neon/Railway/Supabase).
